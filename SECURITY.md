# Security Policy

## Supported Versions

`matia-python-client` is currently in pre-1.0 alpha. Only the latest released
version is supported with security fixes.

| Version    | Supported |
| ---------- | --------- |
| 1.0.0a2    | Yes       |
| < 1.0.0a2  | No        |

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.
Instead, email **nloding@matia.io** with a description of the issue and
steps to reproduce it. We'll acknowledge receipt as soon as we can and work
with you on a fix and disclosure timeline.
