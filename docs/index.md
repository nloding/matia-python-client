# matia-client

An idiomatic, fluent Python client library for the [Matia](https://matia.io) API.

This is a library only — import it into your own scripts/services. It is not a CLI tool.

It covers:

- **Assets** — create and update data assets
- **Integrations** — list, run, and configure syncs; a chainable builder for creating Postgres and Google Analytics 4 integrations
- **Tags** — create, edit, and assign tags to resources
- **Users** — list users
- **Audit Logs** — list and auto-paginate audit log events

See [Quickstart](quickstart.md) for usage examples, or jump straight into the [API Reference](reference/client.md).
